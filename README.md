# Have You Tried Turning It Off?

One funny line a hopeless tech support agent gives a desperate customer — a make.fun bounty entry.

[![Bounty](https://make.fun/badge/u-motasimfuad-have-you-tried-turning-it-off-154a938b.svg)](https://make.fun/bounty/u-motasimfuad-have-you-tried-turning-it-off-154a938b)

[![Reward](https://make.fun/badge/u-motasimfuad-have-you-tried-turning-it-off-154a938b/MrYos99/have-you-tried-20261125/reward.svg)](https://make.fun/bounty/u-motasimfuad-have-you-tried-turning-it-off-154a938b)

`main.py` writes the entry line to `/output/entry.txt` (UTF-8, 1–199 characters), which the judge compares two at a time.

## Run

```sh
python3 main.py
```

The entry line is written to the directory in `MAKEFUN_OUTPUT_DIR` (default `/output`).
